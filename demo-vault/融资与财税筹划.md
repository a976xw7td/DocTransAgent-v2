# 融资与财税筹划

## 概述

出海财税架构直接影响企业的融资能力、利润回流效率和整体税负。架构设计应在进入市场前完成，事后调整成本极高。

## 常见出海架构

### 红筹架构
```
开曼群岛控股公司（HoldCo）
    └── 香港中间层（OpCo HK）
            └── 境内/境外运营实体
```
**适用场景**：计划在美/港上市，或引入境外机构投资者  
**优势**：便于境外融资、股权激励、利润留存  
**注意**：需满足 ODI/37号文等境内报批要求

### 直接持股架构
```
中国母公司
    └── 海外子公司（WFOE / JV）
```
**适用场景**：战略性出海，不考虑境外上市  
**优势**：结构简单，便于管控  
**劣势**：利润回流需缴预提税（withholding tax）

## 税务筹划要点

### 转让定价（Transfer Pricing）
- 关联方交易须符合独立交易原则
- 需准备同期文档（master file + local file）
- 高风险地区：印度、巴西、德国

### 预提税优化
各地股息预提税率（对中国母公司）：
| 目标国 | 标准税率 | 协定税率 |
|--------|---------|---------|
| 香港 | 0% | — |
| 新加坡 | 0% | — |
| 越南 | 5% | 5% |
| 印尼 | 20% | 10% |
| 德国 | 25% | 5%（持股≥25%） |
| 美国 | 30% | 10% |

**策略**：通过香港或新加坡中间控股公司降低预提税率

### 研发费用加计扣除
- 中国境内研发费用可享受175%加计扣除
- 注意：境外研发活动不适用

## 出海融资渠道

### 境内融资支持出海
- 国家开发银行"出海贷"
- 中国进出口银行优惠贷款
- 地方政府出海补贴（部分城市有专项资金）

### 境外融资
- **PE/VC**：适合高成长性业务，需红筹架构
- **银团贷款**：适合大型基础设施项目
- **债券融资**：亚洲美元债、绿色债券
- **当地政策性银行**：如越南发展银行、印尼BRI

## 外汇管理

- 境外投资需完成 **ODI 备案**（商务部+发改委+外汇局）
- 利润回流须提供完税证明
- 跨境资金池（现金池）可提升资金使用效率
- 注意：部分国家有外汇管制（印度、印尼、越南）
