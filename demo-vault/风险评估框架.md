# 风险评估框架

## 概述

出海风险是多维度的，需要系统化识别和管理。本文提供一套适用于不同市场和业务类型的风险评估框架，供制定 [[市场准入策略]] 和 [[融资与财税筹划]] 时参考。

## 风险分类体系

### 一、政治与主权风险
| 风险 | 描述 | 主要地区 |
|------|------|---------|
| 政权更迭 | 新政府推翻前任政策 | 东南亚、非洲、拉美 |
| 资产国有化 | 政府强制收购外资企业 | 委内瑞拉、玻利维亚 |
| 制裁风险 | 被纳入美国/欧盟制裁名单 | 中资企业在美业务 |
| 地缘冲突 | 战争或领土争端影响运营 | 中东、东欧 |

**应对措施**：
- 购买政治风险保险（中国出口信用保险公司 / MIGA）
- 采用合资结构分散风险
- 避免单一市场过度集中

### 二、监管与合规风险
- 法规突变（如印度突然收紧外资准入）
- 数据合规处罚（参见 [[合规与法律要求]]）
- 反垄断调查
- 环保与劳工标准

### 三、汇率与金融风险
- 目标货币大幅贬值（如土耳其里拉、阿根廷比索）
- 外汇管制导致利润无法回流
- 融资成本上升（利率风险）

**对冲工具**：
- 远期合约（Forward Contract）
- 货币互换（Currency Swap）
- 自然对冲（收入与成本同币种）

### 四、运营风险
- 供应链中断（参见 [[供应链本地化]]）
- 关键人才流失（参见 [[跨文化管理]]）
- 网络安全与数据泄露
- 自然灾害（台风、地震高发区）

### 五、市场风险
- 需求不及预期
- 本地竞争对手反应（参见 [[竞争对手分析]]）
- 消费者偏好与预判不符
- 渠道合作方违约

## 风险评分矩阵

```
影响程度
  高 |  关注  |  重点管控  |  立即处置  |
  中 |  监控  |  关注      |  重点管控  |
  低 |  接受  |  监控      |  关注      |
      -------|------------|-----------|
         低          中          高
                发生概率
```

## 尽职调查清单

进入新市场前需完成：
- [ ] 政治稳定性评级（Freedom House, EIU）
- [ ] 营商环境排名（世界银行 Doing Business）
- [ ] 目标合作伙伴背景调查（KYC/AML）
- [ ] 土地/物业权属核查
- [ ] 现有诉讼和监管处罚记录
- [ ] 当地律师意见书
- [ ] 财务审计（收购场景）

## 风险监控机制

- 每季度更新风险登记册
- 设置预警指标（KRI）
- 重大风险事件48小时上报机制
- 年度风险委员会审查
