# 出海启动检查清单

> 在做出进入新市场的最终决策前，完成以下各项。未完成项需标注原因。

## 阶段一：市场验证（决策前3-6个月）

### 市场调研
- [ ] 目标市场 TAM/SAM 估算完成
- [ ] 完成至少10个目标客户深度访谈
- [ ] 竞争格局分析完成（参见 [[竞争对手分析]]）
- [ ] 本地行业协会或商会建立联系

### 可行性评估
- [ ] 盈亏平衡测算（含本地化成本）
- [ ] 市场准入模式选定（参见 [[市场准入策略]]）
- [ ] 初步财税架构方案（参见 [[融资与财税筹划]]）
- [ ] 主要风险识别完成（参见 [[风险评估框架]]）

## 阶段二：进入准备（决策后0-6个月）

### 法律与合规
- [ ] 当地律师事务所聘用
- [ ] 公司注册文件准备完毕
- [ ] 关键合规要求清单完成（参见 [[合规与法律要求]]）
- [ ] 知识产权（商标/专利）申请提交

### 人员
- [ ] 本地 Country Manager 确定
- [ ] 本地 HR/法务负责人到位
- [ ] 外派人员清单及工签申请启动
- [ ] 本地薪酬基准调研完成（参见 [[跨文化管理]]）

### 运营
- [ ] 办公/厂房选址完成
- [ ] 核心供应商初步筛选（参见 [[供应链本地化]]）
- [ ] IT 系统本地化方案确定
- [ ] 银行账户开立完成

## 阶段三：运营启动（第6-12个月）

- [ ] 首批客户/订单签署
- [ ] 本地团队达到最低运营规模
- [ ] 供应链双源认证完成
- [ ] 季度风险回顾机制建立
